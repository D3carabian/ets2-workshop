# P4 实现与验收（2026-10-03）

基线为已合并阶段二、三的 `736b56d`。实施前已有选车分页、独立滚动、配件搜索、分组与属性对照；缺少完整游戏名称、语言切换及明确的只读原因。本轮补齐这些内容，没有扩展底盘/驾驶室移植或 Mod 支持，也没有放宽后端改装规则。

## 逐项验收

| 计划要求 | 当前行为与证据 |

| 搜索、类别与前后参数 | 名称搜索同时覆盖中英游戏文本、原始路径和显式 hp；按游戏分类语义分组，候选与目录均能翻页访问全部匹配项。对照功率、扭矩、转速、齿比和独立油箱容量，展开可核对来源。 |

## 游戏文本覆盖

通过有界、只读 HashFS v2 读取 `locale.scs`，展开英语与简体中文 `local.sii` 及补充文件。基础归档每种语言得到 12,963 个有效键；注释掉的旧键不计入，也不将未知键伪造成已解析名称。游戏文本只进入用户的本地配件缓存，不随程序发布。

本机安装的原版与已识别官方 DLC 共扫描 26,382 个定义；其中卡车及共享轮件范围有 **21,117 个**。取得双语游戏名称 **20,634 个（约 97.7%）**，含 4 个用精确路径、相同模型/图标/外观状态复核的旧键兼容映射。

| 主要类别 | 双语游戏名称 / 定义数 |
| --- | ---: |
| 发动机 | 203 / 203 |
| 变速器 | 195 / 195 |
| 底盘 | 164 / 164 |
| 驾驶室 | 78 / 78 |
| 内饰 | 405 / 405 |
| 独立油箱 | 61 / 61 |

剩余 483 个中，467 个定义本来没有 `name`，16 个有名称键但没有足够证据确认有效文本。它们保留游戏类别、变体、原始字段和路径，不编造官方名称。之前 74 个 `unknown` 轮组已按明确路径拆回轮毂盖、轮辋及车轮，游戏名称均可解析。

详细方法、游戏/Wiki 交叉核对及未确认别名见 [语言包研究](LOCALE_RESEARCH.md)、[类别与缺失键核对](P4_CATEGORY_KEYS.md)。覆盖率对应这份安装内容，不声称其他版本或全部 DLC 也相同。盐值/压缩/编码不受支持或文件损坏时会保留回退名称并显示目录提示。

## 升级已有目录

旧目录仍能打开；界面提示通过“设置 → 建立 / 更新目录”读取游戏名称。配置或目录刷新后读取后端真实名称状态和警告，不把一次索引成功误认为文本解析全部成功。存在待保存修改时禁止重建目录，先保存或移除操作，避免丢失修改。

## 验证结果

- `scripts/build.ps1 -CheckOnly` 通过：53 项 Rust 测试、15 项前端名称/排序/规则/语言测试、TypeScript/Vite 构建、格式检查、10 项 Node 环境检查、21 项打包回归及许可收集。3 项依赖本机游戏的 Rust 测试默认忽略，已单独显式运行通过。
- `scripts/p4-native-smoke.mjs`：真实 Tauri/WebView + 合成存档，验证双语名称、品牌排序、超过 150 个候选的完整分页、底盘只读说明、语言切换保留操作、阻止带待修改清单重建目录，以及实际另存。
- `scripts/language-ui-smoke.mjs`：真实 React + 合成 IPC，验证向导草稿、搜索、保存弹窗、语言偏好及后端错误原文。明确不作为真实文件写入的证据。
- `scripts/garage-ui-smoke.mjs`：1440×940 与 1080×720 的实际 WebView 验证，包含旧目录提示条。工作区高度按实际剩余空间计算，底部选车不会带动整页或右侧滚动，翻页/搜索按钮保持可见。
- 首次配置合成资源桌面回归通过；5,000 辆车保存/未确认历史/恢复回归通过，本机 debug 单次打开约 849 ms，仍只渲染 50 张车辆卡。所有桌面验收页面异常为零。
- 使用本机真实名称目录与合成车辆做了中文、英文目检；没有编辑玩家存档。截图、名称覆盖报告和只读审计输出留在 Git 忽略的 `verification/`。

复现基础检查：

```powershell
./scripts/build.ps1 -CheckOnly
cargo build --locked --features custom-protocol --manifest-path src-tauri/Cargo.toml --bin ets2-workshop
node scripts/p4-native-smoke.mjs
node scripts/language-ui-smoke.mjs
node scripts/recovery-smoke.mjs
node scripts/onboarding-smoke.mjs
```

名称覆盖实机检查使用 `ETS2_GAME_DIR` 和 `ETS2_EXISTING_CACHE` 指向已有游戏及已解包目录，运行 `cargo test --lib catalog::name_tests::installed_catalog_name_coverage -- --ignored --nocapture`。此检查只读游戏/已有缓存，结果写入工作区 `verification/p4-names/`；不会提交游戏词库。普通 CI 不需要安装游戏。

本轮未制作公开安装包、推送或发布；English 以完整可用为目标，没有进行独立视觉设计。任意改装组合仍须区分结构校验与游戏内兼容性验证。
