# 存档列表性能与自动存档筛选（2026-10-03）

车库与改装记录的存档选择提供“包含自动存档”，默认关闭并在本机记住选择。按内部槽位目录名识别 `autosave` 和 `autosave_*`（不区分大小写）；保留 `quicksave` 和手动存档，即使手动名称中含有 autosave。筛选在读取 `game.sii` 元数据及解码 `info.sii` 之前执行。

切换筛选会刷新列表并调整失效的下拉选项，不改变已打开的编辑会话和待保存修改。车库单独显示当前已打开的名称，避免把下拉框选择误认为当前编辑对象。复查目标被筛掉时清空选择。刷新失败时恢复原开关值。

## 测量

同一台 Windows 机器的 debug 桌面构建、相同文件集。旧版基准为提交 `2f3476f`。脚本创建 10 个手动存档、1 个快速存档和 100 个自动存档，所有 `info.sii` 都经过 ScsC 加密；自动发现另外只读枚举了 26 个 Steam Cloud 槽，因此完整扫描总数 137，默认筛选后 16。测试打开、写入及完整性检查只针对合成文件；未修改真实玩家数据。

| 操作 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 完整列表重复刷新（137 个） | 7,284 ms | 40 ms |
| 默认排除自动存档后的重复刷新（16 个） | 未提供筛选 | 9 ms |
| 本次进程首次包含未缓存的自动存档 | 每次都解码 | 6,374 ms |

独立审查修复后的再次测量：完整列表重复刷新 36 ms、默认筛选 8 ms、隐藏后再开启约 52 ms（包含 UI 点击与列表更新）。

首次启动和首次包含某些存档仍需解码它们；本次优化主要消除重复解码，并允许从首次扫描就跳过不需要的自动存档。计时不作为跨机器固定承诺。

## 缓存与正确性

只在当前应用进程缓存成功解析的名称。每次刷新仍读取 `info.sii` 的内容摘要，所以同长度、同修改时间的改名不会陈旧；文件锁定、损坏或读取失败会显示错误，不拿旧名称掩盖。首次解码后再次核对内容，遇到读写竞争提示刷新。新建／删除和 `game.sii` 修改时间每次重新枚举。设置改变时清空缓存，错误不缓存。关闭自动存档筛选保留已解码的自动存档名称；再次开启时检查内容和删除情况，不重复解码未变化的名称。加密信息继续使用原有隔离解码进程，未降低解码边界。

Rust 合成测试覆盖解码调用次数、筛选顺序、快速存档、同时间改名、新建／删除、读取时变化、缓存命中后文件锁定和恢复。桌面测试覆盖开关、跨刷新持久化、隐藏后重新显示仍复用名称缓存、切换后保留当前会话、所有合成 `game.sii` 不变。资源准备性能记录见 [CATALOG_PERFORMANCE.md](CATALOG_PERFORMANCE.md)。
