# MVP 独立审查与验证

## 0.2.0 底层与首次启动审查

新增独立审查发现并修复 DecryptTruck 上游的多枚举字段共享字典问题：每个字段现在使用自身字典，未知枚举值明确拒绝。也补齐中文 UTF8 字节转义与小地址匿名 ID 格式。两份合成 BSII 回归样本不含玩家数据；6 份本机存档/信息副本加 2 份合成样本与旧 DLL 的解码文本统一换行后完全一致。独立审查已复核修复。

首次启动测试覆盖自动检测、错误目录拒绝、用户确认前不保存设置、官方解包器下载及双重哈希校验、目录建立与完成状态持久化。WebView2 检测和官方下载文件签名校验通过；未在本机卸载已安装的运行时来实测缺失环境安装。

首次发布前，构建、测试与打包已在本地验证。GitHub 托管工作流的最新结果以仓库 Actions 页面为准。

以下记录为 0.1.0 初版审查。

审查 Agent 以 `fork_turns: none` 启动，没有继承主对话。它读取 README、Rust 核心、React 界面和测试，并用本机配件目录独立复现问题。没有改动真实游戏存档。

## 审查发现及修复

1. 外观件仅校验候选自身，未检查现有附件反向冲突。已改为检查最终附件集合中每个约束的新增违反；既有跨品牌适配差异不会掩盖新增冲突。独立复现包括 Volvo 镜子与遮阳板。
2. 多轴轮胎复查误以为同类别任何位置命中就算保留。现在记录 `offset` / `wheel_index` / 挂点位置，位置不唯一则报告歧义。
3. 外观追加类别使用了与资源目录不一致的名称。现在使用实际的 `beacon`、`r_grill`、`f_grill`、`sunshld`，兼容少量 `sunshield` 类别。

Agent 最后一次复核确认这些发现均有对应修复。最后一轮复核为静态检查；主 Agent 负责最终构建与运行测试。

## 自动验证

- Rust：2 项解析测试、10 项核心工作流测试通过。涵盖原文保留、未知字段、引用完整性、单字段替换、核心单例拒绝、附件克隆与依赖、跨编码动力类型拒绝、unit ID 变化、反向冲突、多轴定位、备份恢复和并发更新拒绝。
- 配件目录：从本机本体与已识别官方 DLC 建立 26,382 个配件定义。程序保存来源资源大小和修改时间，资源变更后要求重新索引。
- 桌面 UI：使用正式 Tauri EXE 和实际 WebView，通过工作区中的加密存档副本验证车库枚举、重复发动机拒绝、Volvo 发动机替换、预览、另存、复查、恢复；无 JavaScript 页面错误。
- 测试数据、截图和机器可读结果在被 Git 忽略的 `verification` 目录。解包缓存移动到应用数据目录供实际使用。

## 验证边界

桌面自动验证没有启动游戏来测试所有新组合。此前用户实际验证过独立 DAF 油箱与 Volvo 发动机替换、游戏重新保存、维修行为。任意外观模型组合仍需游戏内验证，MVP 限制为明确规则与已有供体模板。

未纳入 MVP：Mod 加载优先级解析、任意底盘/驾驶室移植、携带子挂件的复杂附件克隆、精确极速预测。
