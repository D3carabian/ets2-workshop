## 简体中文

### 本次更新

- 存档列表新增“包含自动存档”开关，默认保留手动和快速存档；未变化的名称复用缓存，减少刷新等待。
- 游戏资源按需读取，未变化的配件目录直接复用；需要官方解包工具时才下载并校验。
- 中英文界面与游戏配件名称，突出品牌、型号和关键参数；补齐跨包引用，修复注释与重复定义字段导致的遗漏。
- 车库、配件和候选列表独立滚动，统一选择器与文字对齐，采用新的卡车徽章。
- “备份与恢复”提供明确入口；选配件时提示保存前自动备份，保存成功后显示真实备份状态。游戏另存后的配件检查单独说明，不与恢复混淆。
- 修复配置发布失败、游戏目录切换、目录过期检查，以及撤销无关操作时新增附件引用失效的问题；保留备份、恢复和原文件变化保护。

### 安装与升级

下载下面的 Windows x64 ZIP，**完整解压后运行 `ETS2 Workshop.exe`**，保留同目录的其他文件。无需安装 Node、Rust 或 Truck Tools；界面需要 Microsoft Edge WebView2 Runtime。

旧版本配件目录升级后仍可查看；若提示需要更新，请在“设置 → 建立 / 更新目录”重建一次。工具不会因升级自动修改游戏存档。

仍为公共预览：支持原版与已识别的官方 DLC，不支持 Mod。默认另存新档；覆盖或恢复前请退出游戏并暂停会写入该槽位的同步程序。维修站改装升级可能重置混搭配件，不能保证所有外观组合均兼容。

## English

### Changes

- Optional autosave listing, with manual saves and quicksaves shown by default. Unchanged save names are cached for faster refreshes.
- Selective game archive reading and reusable catalog results. The verified official extractor is downloaded only when extraction is needed.
- Chinese/English UI and in-game part names, emphasizing brands, models and specifications. Cross-archive includes, comments and repeated definition fields are handled more accurately.
- Independent garage and parts scrolling, aligned controls and the new truck badge.
- Clear Backups & restore entry points and truthful backup status after saving. Checking parts after an in-game save is explained separately from restoring a backup.
- Fixes for configuration publication failures, game installation switching, stale catalogs and added-accessory references after undoing unrelated changes. Backup, recovery and source-change protections remain in place.

### Install and upgrade

Download the Windows x64 ZIP below, **extract everything and run `ETS2 Workshop.exe`**. Keep the accompanying files. Node, Rust and Truck Tools are not required; Microsoft Edge WebView2 Runtime is required for the interface.

Older catalogs remain viewable. If prompted, rebuild once in Settings → Build / update library. Upgrading does not automatically modify game saves.

Public preview: base game and recognized official DLC only; Mods are unsupported. Saving to a new slot is the default. Before overwriting or restoring, exit the game and pause programs that synchronize the slot. Service-station customization may reset mixed-brand parts; not every appearance combination is verified.
