## 简体中文

### 本次更新

- 全新 Cockpit 工作台：三栏独立滚动、自定义标题栏、配件仪表与替换前后参数比较。
- 外观支持跟随系统、日间和夜间模式，自动记住选择。日间采用对比更清晰的深蓝色；设置卡片对齐，静态文本不再像网页一样拖选，输入框仍正常编辑。
- 变更清单不再占据车库底部。悬停右上角“保存修改”可预览，点击进入完整确认页，检查或移除修改后统一另存或备份覆盖。
- 退出时提醒尚未保存的改装；返回、关闭提醒或按 Esc 都会打开变更清单。保存过程中阻止丢弃退出，失败时保留修改和手工输入的名称。
- 识别车辆的玩家/雇员归属，支持驾驶员英文姓名搜索，按当前车辆、其他车辆、雇员车辆稳定分组。姓名从本机游戏读取，未知归属不猜测。
- 新存档默认使用日期时间命名；保留自动存档开关防误触、候选再次点击取消、源文件变化检测和备份恢复保护。
- 发布包包含项目 MIT 许可证及字体、依赖的各自许可证。

### 安装与升级

下载 Windows x64 ZIP，**完整解压后运行 `ETS2 Workshop.exe`**，不要单独移动 EXE。无需 Node、Rust 或 Truck Tools；界面需要 Microsoft Edge WebView2 Runtime，缺少时启动器提供微软官方手工安装指引。

升级不会自动修改游戏存档。旧配件目录仍可使用；如需补充驾驶员英文姓名，在“设置 → 建立 / 更新目录”更新一次。

仍为公共预览：支持原版及已识别的官方 DLC，不支持 Mod。当前编辑流程使用关闭 Steam 云同步后的本地手动存档；World of Trucks 外部任务兼容性未验证，编辑前请结束外部任务。默认另存新档，覆盖或恢复前请退出游戏并暂停会写入该槽位的同步程序。游戏内改装升级可能恢复原厂部件，并非所有混搭组合都已进游戏验证。

## English

### Changes

- New Cockpit workspace with independently scrolling columns, a custom titlebar, part gauges and before/after specification comparisons.
- Follow system, day and night appearance modes with a remembered preference. Day mode uses higher-contrast blue accents. Settings cards align; static labels no longer behave like selectable webpage text, while inputs remain editable.
- Pending changes no longer occupy the bottom of the garage. Hover over Save changes for a preview, or open the complete review to inspect and remove changes before saving them together to a new slot or backing up and overwriting.
- Unsaved changes are checked on exit. Returning, dismissing the reminder or pressing Escape opens the change review. Discarding is blocked while saving; failures preserve staged changes and the typed save name.
- Player/employee vehicle assignments, English driver-name search and stable grouping of the active truck, other trucks and employee trucks. Names are read from the installed game; unknown assignments are not guessed.
- Timestamp-based default save names, safer autosave checkbox targeting, click-again candidate deselection, source-change checks and backup/recovery protection.
- The package includes the project's MIT license and the separate licenses for bundled fonts and dependencies.

### Install and upgrade

Download the Windows x64 ZIP, **extract everything and run `ETS2 Workshop.exe`**. Keep the accompanying files. Node, Rust and Truck Tools are not required. The UI requires Microsoft Edge WebView2 Runtime; if missing, the launcher provides Microsoft's official manual installation instructions.

Upgrading does not automatically modify saves. Existing catalogs remain usable; run Settings → Build / update library once to add English driver names if needed.

Public preview: base game and recognized official DLC only; Mods are unsupported. The supported editing workflow uses local manual saves with Steam Cloud disabled. World of Trucks external-job compatibility is unverified; finish external jobs before editing. Saving to a new slot is the default. Before overwriting or restoring, exit the game and pause programs that write or synchronize the slot. In-game upgrades may restore factory parts; not every mixed-part combination has been tested in the game.
